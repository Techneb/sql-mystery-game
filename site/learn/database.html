The bakery database

Every example in this handbook runs on this one small, invented database, so you only have to learn its tables once.

The bakery sells ten products and keeps four tables. They record one week of trade, from Monday 2 March to Sunday 8 March 2026.

TableColumnsOne row is
customerid, name, town, joined, referred_bya regular customer; referred_by is the id of the customer who recommended the shop, or NULL
productid, name, category, pricesomething on sale: bread, pastry or cake, price in euros
ordersid, customer_id, day, timeone visit to the counter; day is YYYY-MM-DD, time is HH:MM
order_itemorder_id, product_id, quantityone line of an order: how many of one product

The ids link the tables: each order line points to its order and its product, each order to its customer, and a customer to the customer who referred them. The schema draws those links: a gold key marks each primary key, a silver one each foreign key, and every line runs from a foreign key (N, many rows can share a value) to the key it points to (1). The loop beside customer is referred_by, which points back into the same table.

primary key foreign key one-to-many

The full database is eight customers, ten products, fourteen orders and twenty-three order lines. To run the examples yourself, paste this script into any SQLite tool (the sqlite3 command line, DB Browser for SQLite, or an online SQLite playground), then try each query from the pages below. The examples follow the rules of this site's terminal, which plain SQLite relaxes in one place: there LIKE ignores case and ILIKE does not exist, so write lower(name) LIKE '%croissant%' instead of ILIKE.

The bakery database as a SQLite script 
CREATE TABLE customer (id INTEGER PRIMARY KEY, name TEXT, town TEXT, joined TEXT, referred_by INTEGER REFERENCES customer(id));
CREATE TABLE product (id INTEGER PRIMARY KEY, name TEXT, category TEXT, price REAL);
CREATE TABLE orders (id INTEGER PRIMARY KEY, customer_id INTEGER REFERENCES customer(id), day TEXT, time TEXT);
CREATE TABLE order_item (order_id INTEGER REFERENCES orders(id), product_id INTEGER REFERENCES product(id), quantity INTEGER);
