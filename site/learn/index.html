The Clerk's Handbook

Plain-English pages on the SQL that The Ritz Affair practises, for a first SQL course. Every example runs in SQLite on a small bakery database, never the game's archives, so nothing here gives a chapter away.

  1. The bakery database: the example data, with a script to recreate it.
  2. Tables, keys and the schema: keys, relationships, exploring a database.
  3. SELECT and WHERE: choosing columns and filtering rows.
  4. ORDER BY and LIMIT: sorting and keeping the top rows.
  5. LIKE and text patterns: searching text with wildcards.
  6. GROUP BY, aggregates and HAVING: counting and summing per group.
  7. JOIN, LEFT JOIN and self-joins: combining tables and finding what is missing.
  8. CASE WHEN: labels, buckets and conditional counts.
  9. Window functions: RANK and LAG: ranking rows and comparing with the previous one.
  10. CTEs and WITH RECURSIVE: named steps and following chains.
