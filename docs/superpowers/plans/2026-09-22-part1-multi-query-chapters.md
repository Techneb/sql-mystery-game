# Part I Multi-Query Chapters Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every Part I chapter (1-8) requires at least one real discovery query before the chapter's
construct-teaching query, instead of the objective handing every `WHERE`-clause constant directly;
all hints are removed for now.

**Architecture:** Content-only change to `plot.py` (chapter dicts gain a `discovery` field; all
`hints` become `[]`) and `generate_db.py` (one new planted row, a `check_discovery` assertion
folded into the existing `check_chapter`, and `solution_sql` prints discovery queries too). One
one-line site fix in `site/app.js` so the now-empty hint button doesn't render inertly. No schema
change, no `chapters.json` shape change beyond `hints` being empty and a new dev-only `discovery`
field on chapter dicts that is never shipped to the client (only `TEXT_KEYS` fields plus `hints`
reach `chapters_json()`).

**Tech Stack:** Python stdlib only (unchanged). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-09-22-part1-multi-query-chapters-design.md`

In `generate_db.py`, add this function immediately above `def check_chapter(conn, V, ch):`:

```python
def check_discovery(conn, V, ch):
    """Each chapter's discovery queries must actually surface the fact the story withholds."""
    for d in ch.get("discovery", []):
        rows = conn.execute(d["query"].format(**V)).fetchall()
        if "row_count" in d:
            assert len(rows) == d["row_count"], \
                "chapter %s discovery: got %d rows, expected %d (%s)" % (ch["n"], len(rows), d["row_count"], d["query"])
        if "must_contain" in d:
            needle = d["must_contain"].format(**V)
            assert needle in str(rows), \
                "chapter %s discovery: %r not found in %r (%s)" % (ch["n"], needle, rows, d["query"])
```

Then change the first line of `check_chapter`'s body (`def check_chapter(conn, V, ch):` docstring
line stays, first executable line changes) from:

```python
    want = normalise(str(V[ch["answer_key"]]))
```

to:

```python

    want = normalise(str(V[ch["answer_key"]]))
```
