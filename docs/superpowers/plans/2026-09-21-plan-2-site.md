# Plan 2 — Site (Investigate mode) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static page under `site/` where a pair of students plays The Ritz Affair end to end in the browser: terminal, answer flow, ERD that reveals tables as evidence arrives, case board, Lupin's telegrams, witnesses (hints), badges, rank, printable certificate, notepad — reading only the files Plan 1 generates.

**Architecture:** Three hand-written files: `site/index.html` (landing overlay + game page), `site/style.css` (newspaper look, three-column layout, print stylesheet), `site/app.js` (an ES module: pure functions exported for tests, `boot()` runs only in a browser). `sql.js` from cdnjs opens `mystery.sqlite` in memory; `chapters.json` drives all text; `schema.svg` is inlined and filtered. All state lives in one `localStorage` key. `test_site.mjs` at the repo root tests the pure functions with Node's built-in runner.

**Tech Stack:** Vanilla HTML/CSS/JS (ES2020 modules), `sql.js` 1.13.0 from cdnjs (verify the exact version exists with `curl -sI https://cdnjs.cloudflare.com/ajax/libs/sql.js/1.13.0/sql-wasm.js`; fall back to 1.12.0), Google Fonts (Playfair Display, Special Elite, Cormorant Garamond), `crypto.subtle`, Node >= 20 for `node --test`. No framework, no bundler, no npm.

**Spec:** `docs/superpowers/specs/2026-09-20-sql-mystery-game-design.md` sections 3 (game rules, badges, rank), 5 (layout and look), 6 (site). Inputs from Plan 1: `site/chapters.json`, `site/schema.svg`, `site/mystery.sqlite`.

## Global Constraints

- Everything in `site/` is pure ASCII except what comes from `chapters.json` (already ASCII). Copy in the page: English, in character, dry.
- Colours as tokens on `:root`: paper `#f3ead7`, ink `#1c1a17`, red `#8a2b2b`, terminal `#0f0d0a`, terminal text `#d9c89a`, gold `#c9a35a`, card `#fffdf5`.
- Layout: masthead, then three columns `260px 1fr 320px` (ERD | terminal | story); under 900 px they stack ERD / terminal / story; phone width works with 16 px gutters and no horizontal scroll.
- Never hard-code chapter text, answers or table names in the page: they come from `chapters.json` and `schema.svg`. The Part II code and every answer are compared only as SHA-256 of the normalised input.
- `app.js` must import in Node without a DOM: no top-level `document`/`window` access; `boot()` is called only `if (typeof document !== "undefined")`.
- Results display capped at 200 rows; SQLite errors shown verbatim.
- All `localStorage` access wrapped in try/catch; the page renders without it.
- Commit after every task; end commit messages with the trailer lines given in the launch instructions.

```js
// site/app.js -- The Ritz Affair. ES module: pure functions exported for node --test, boot() only in a browser.
export const STOP_WORDS = new Set(["the", "a", "suite", "no", "trunk", "mr", "mrs", "esq", "lord", "senor",
  "senora", "comtesse", "de", "rue", "report", "telegram", "account", "plate"]);

export function normalise(s) {
  // Same rules as normalise() in generate_db.py. Keep both in sync (fixture in chapters.json).
  const tokens = (String(s).toLowerCase().match(/[a-z0-9]+/g) || []).filter(t => !STOP_WORDS.has(t));
  if (tokens.length && tokens.every(t => /^[0-9]+$/.test(t))) return tokens.join("");
  return tokens.join(" ");
}

export async function sha256(s) {
  const buf = await crypto.subtle.digest("SHA-256", new TextEncoder().encode(s));
  return [...new Uint8Array(buf)].map(b => b.toString(16).padStart(2, "0")).join("");
}
```

```js
export function currentChapter(state, chapters) {
  const next = state.solved.length + 1;
  const cap = state.part2 ? 12 : 8;
  return chapters.find(c => c.n === Math.min(next, cap));

export function awaitingCode(state) { return part1Done(state) && !state.part2; }
```

```js
export const ROW_CAP = 200;
const esc = s => String(s === null || s === undefined ? "NULL" : s).replace(/[&<>]/g, c => ({ "&": "&amp;", "<": "&lt;", ">": "&gt;" }[c]));

export function renderResults(res) {
  if (!res) return '<p class="muted">No rows.</p>';
  const head = "<tr>" + res.columns.map(c => "<th>" + esc(c) + "</th>").join("") + "</tr>";
  const body = res.values.slice(0, ROW_CAP).map(r => "<tr>" + r.map(v => "<td>" + esc(v) + "</td>").join("") + "</tr>").join("");
  const more = res.values.length > ROW_CAP ? '<p class="muted">' + (res.values.length - ROW_CAP) + " more rows not shown.</p>" : "";
  return "<table>" + head + body + "</table>" + more;
}

export function pushHistory(state, sql) {
  if (state.history[0] !== sql) state.history.unshift(sql);
  state.history = state.history.slice(0, 20);
}

function runQuery() {
  const sql = $("sql").value.trim();
  if (!sql) return;
  const ch = currentChapter(state, data.chapters);
  state.queries[ch.n] = (state.queries[ch.n] || 0) + 1;
  state.totalQueries++;
  pushHistory(state, sql);
  let res = null, error = null, t0 = performance.now();
```
