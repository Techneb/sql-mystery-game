# Closing videos

Two short films made on OpenGen (Nano Banana Pro for the stills, Veo 3.1 to animate them), one per file, each a
step-by-step checklist with the settings, the references to upload, the prompts to paste and the file names
to save:

- `video-part1.md`: **"The Boat Train"**, closes Part I (top of the Chapter VIII extra edition). Starts with
  the two reference images both films use (Ganimard's sheet, the style frame).
- `video-part2.md`: **"Case Closed, Twice"**, closes Part II (after chapter XII).

Clips go to `assets-source/`; the assembly (cuts, cross-fades, captions, MP4/WebM, poster) is done on
the Mac with ffmpeg, then the films are wired into the page.
